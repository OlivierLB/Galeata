# Galeata

[Français](docs/fr/README.md) · [English](docs/en/README.md)

Un IDE local pour développer avec Codex et Claude Code : fichiers, code, terminal, Git et plan vivant dans le même espace.

A local IDE for developing with Codex and Claude Code: files, code, terminal, Git and a live plan in one workspace.

**Linux x86_64 · Version 0.1.0 en développement / in development.**

## Installation

```sh
curl -fsSL https://raw.githubusercontent.com/OlivierLB/Galeata/main/install.sh | sh
```

Sans sudo. Claude Code ou Codex est nécessaire pour utiliser les agents. L’interface est actuellement en français.

No sudo required. Claude Code or Codex is required to use agents. The application interface is currently in French.
