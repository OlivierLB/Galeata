# Contribuer à Galeata

Les corrections et améliorations sont les bienvenues dans le projet officiel. Pour un changement important, ouvrez d’abord une issue afin de discuter du besoin.

1. Créez un fork et une branche consacrée à votre changement.
2. Suivez les instructions de [développement](development.md) et les conventions de [CLAUDE.md](../../CLAUDE.md).
3. Vérifiez les changements avec les commandes adaptées décrites dans le [guide de développement](development.md).
4. Ouvrez une pull request vers `main`, en expliquant le problème, le changement et les vérifications réalisées.

## Licence des contributions

En soumettant une contribution destinée à être intégrée à Galeata, vous acceptez de la proposer sous la licence [PolyForm Shield 1.0.0](../../LICENSE). Vous devez disposer des droits nécessaires pour la soumettre. Vous conservez vos droits d’auteur ; aucune cession de propriété n’est demandée.

Signalez les éléments tiers et leurs licences. Ne soumettez pas de code confidentiel, de secrets ou de contenu dont la licence serait incompatible.

## Utilisation et forks

L’usage personnel et professionnel ainsi que les modifications sont permis sous les conditions de la licence. Les forks permettant de préparer une contribution sont les bienvenus. La licence ne contraint pas à contribuer ; elle restreint la fourniture de produits concurrents, même gratuits, selon son texte officiel et ses exceptions. Elle ne constitue pas un blocage technique des copies ni une interdiction générale des forks GitHub.
