# Security

<a id="versions-prises-en-charge"></a>

## Supported versions

Galeata is in active development. Security corrections are applied
to the branch `main` and the latest published version. The old versions
do not receive separate patches.

<a id="signaler-une-vulnérabilité"></a>

## Reporting a vulnerability

Use it [private vulnerability reporting GitHub](https://github.com/OlivierLB/Galeata/security/advisories/new).
Do not publish any flaws or secrets in a issue or pull request public.

Indicate version or commit, reproductive stages, possible impact
and, if necessary, a minimum example without identifiers or personal data.
The maintainer will exchange with you in this private alert and coordinate
publication of the correction. No response period is guaranteed.

If an ID has been exposed, immediately revoke it from the supplier:
delete file or file commit not enough to invalidate a secret.
