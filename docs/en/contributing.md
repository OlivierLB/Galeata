# Contributing to Galeata

Fixes and improvements to the official project are welcome. For a significant change, first open an issue to discuss the requirements.

1. Create a fork and a branch dedicated to your change.
2. Follow the instructions [development](development.md) and the [CLAUDE.md](../../CLAUDE.md).
3. Check the changes with the appropriate commands described in the [development guide](development.md).
4. Open a pull request To `main`, explaining the problem, the change and the checks performed.
