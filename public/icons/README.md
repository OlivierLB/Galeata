# Doodle Icons

Catalogue de 439 icônes de Khushmeen Sidhu, licence CC0.
Source officielle : https://khushmeen.com/icons
Source des tracés : https://github.com/agilek/react-doodle-icons
Révision importée : `43a217f4dc56db621764f2f17a5755f4706b47ec`

Les tracés sont conservés ; seuls les identifiants SVG sont préfixés pour éviter les collisions et la couleur utilise currentColor.
`doodle.svg` contient le sprite ; `doodle/` contient les SVG pour les masques CSS de Monaco.

Utiliser exclusivement le composant `Icon` et les noms du catalogue `src/doodleIcons.ts` pour toute nouvelle icône.
